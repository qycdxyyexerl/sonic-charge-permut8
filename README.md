## Overview

Sonic Charge Permut8 is a real-time audio permutation effect that slices incoming audio into micro-chunks and rearranges, reverses, or stutters them in sync with the beat.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sonic Charge Permut8** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Bit Operations** | XOR, AND, and shift operations on digital audio for glitch effects |
| **Tempo Sync** | All permutations synchronized to BPM for rhythmic results |
| **Instruction Set** | Programmable operation sequence for complex evolving patterns |
| **Randomize** | One-click randomize generates diverse glitch and stutter patterns |
